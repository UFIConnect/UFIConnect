# Project Context: UFIConnect

## 🎯 Core Mission
UFIConnect is a multi-platform ecosystem centered around the "Office" application. A critical architectural component is the **Topic Guardian**, a persistent system designed to maintain data integrity by zeroing out or managing unverified/unknown live posts.

## 🏗️ Architectural Overview
The project follows a distributed architecture with dedicated modules for various platforms and deployment environments.

### 📂 Core Modules
- **`backend/`**: Core server-side logic, including the "Topic Guardian" implementation.
- **`office/`**: The primary "Office" workspace application.
- **`web/`**: The web-based user interface.
- **`mobile/`**: Mobile-specific application logic and release stabilization.
- **`android-twa/`**: Android Trusted Web Activity implementation.
- **`windows/`**: Windows-specific features (including VPN integration).
- **`shared/`**: Shared logic, types, and encrypted Vault data structures used across platforms.
- **`infra/`**: Infrastructure-as-Code, including Cloudflare integration and Office AI services.

### 📂 Support & Operations
- **`deploy/`**: Deployment orchestration and rebranding management.
- **`scripts/`**: Automation and utility scripts (Terminal receipts, coding tasks, etc.).
- **`docs/`**: Technical documentation, including terminal receipt protocols.
- **`marketing/`**: Brand assets and UI/UX branding materials.
- **`.github/`**: CI/CD workflows and GitHub Actions configurations.

## 🚀 Tech Stack & Infrastructure
- **Runtime**: Node.js (managed via `.nvmrc`).
- **Containerization**: Docker (`Dockerfile`, `Dockerfile.backend`, `docker-compose.yml`).
- **Web Server**: Nginx (`nginx.conf`).
- **Process Management**: PM2 (`ecosystem.config.js`).
- **Deployment/Hosting**: Cloudflare (AI & Infra), Render (`render.yaml`).
- **Mobile Frameworks**: Android TWA, Mobile/Windows native integrations.

## 🛡️ Security & Integrity
- **Vault System**: Encrypted data persistence across devices (managed via `shared/`).
- **Topic Guardian**: Active verification of live content streams.
- **Security Protocols**: Hardened account security and consent-based analytics.
