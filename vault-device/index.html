The planned device experience

Turn on. Authenticate. Automate your logins.

After setup, the device is intended to handle sign-ins across your imported accounts. You authenticate when it turns on; supported apps then request the credentials they need. This hardware workflow is planned and is not active in the browser Vault.

First-time setup: import and delete

Turn on the device and authenticate with Face ID on a supported Apple device. Import your passwords, confirm the import succeeded and keep an encrypted recovery backup. Then delete the temporary password export and any source copies you choose to remove.

Deletion is a separate, explicit choice after verification. The planned device must not delete originals before confirming the import and recovery copy.

  1. 01

    Turn on the device

    Power on manually, or open a supported app to trigger the planned automatic wake-up. Saved credentials remain locked until you authenticate.

  2. 02

    Authenticate with Face ID

    Use Face ID on compatible Apple hardware to authorize access when the device turns on. This approval unlocks the planned login workflow.

  3. 03

    Automate imported logins

    Vault fetches each supported app’s authentication request, matches it to the imported account and completes the sign-in. The workflow is intended to work across all imported accounts with supported integrations, without retyping their passwords.

  4. 04

    Shut down automatically

    After completing the sign-in, the device powers off automatically. Opening another supported app starts the flow again when a login is needed.

Face ID requires compatible Apple hardware. Authentication on Android, Windows and Linux, device pairing, recovery and automatic sign-in integrations still need to be developed and validated. Password changes and account recovery may still require your attention.

Security design

Why the workflow requires authentication

Face ID verifies your approval to use Vault. The destination service still verifies its own account credentials and may request another factor. Importing a password does not bypass that service’s security checks.

Protect stored credentials

The device design calls for encrypted credential storage and access gated by authentication. Encryption keys, pairing and recovery must be implemented and independently tested before hardware protection can be claimed.

Keep biometric verification local

On supported Apple hardware, Face ID matches your face within the device’s security system. Apps receive the authentication result, not the stored facial template. Apple’s Face ID security explanation.

Match each request to its account

The planned integration must verify the requesting app or website before using its matching credential. It should release only what that sign-in needs, clear temporary access and shut down after completing the operation.

Automatic shutdown reduces the time the device is active; it does not replace encryption, trusted pairing or recovery safeguards. Multi-factor prompts, expired passwords and unsupported login flows can still require action. These are design requirements for the planned device, not completed hardware certifications.

Before you get started

Can I buy or pair the physical card now?

No. Ordering and hardware pairing are not available. Hardware integration, recovery, security validation and availability must be completed before launch. This preview collects no hardware payment or shipping information.

Does a browser membership provide hardware protection?

The current Vault encrypts items locally in your browser. The planned card has not been connected to that flow. Browser device unlock, where supported, is a separate feature; it does not mean a UFI Vault Card has been paired.

Can the website read my phone or computer's password store?

No. Export a supported file from your existing password manager, then select it in Vault. You review the entries before importing. A password CSV is unencrypted, so delete that temporary file after use and keep encrypted backups for recovery.

Where can I review privacy and subscription terms?

Read the Privacy Policy and Terms of Use. You can manage or cancel your membership in Vault or Settings.
