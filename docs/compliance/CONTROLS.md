## Evidence collection without overstating results

Use the release workflow's artifacts for the exact commit under assessment. Useful local checks include `npm test --prefix backend`, `node --test scripts/web-security.test.mjs scripts/office-security.test.mjs`, `node scripts/check-deployment-security.mjs`, `node scripts/audit-security.mjs`, `node scripts/audit-csp.mjs`, `node scripts/audit-analytics.mjs` and `node scripts/audit-data-preferences.mjs`. Install locked dependencies and build prerequisites first; these commands are a collection plan, not a claim that they were executed for this package.

Capture operating evidence separately: redacted administrative membership and MFA settings, one completed access review, actual alerts and response records, a restore result, supplier review, privacy-request exercise, and a release approval/deployed-commit record. Keep audit artifacts in a restricted store; place only redacted summaries and links in this repository.

The [September security review](../SECURITY-2026-09-15.md) describes a historical source state. Its original memory-only web-session description predates the current persistent HttpOnly cookie; do not reuse it as evidence that browser restarts always end sessions.

Durable billing, privacy rights and Global Privacy Control engineering results are recorded in [ENGINEERING-RELEASE.md](ENGINEERING-RELEASE.md). Attach production and operating-period evidence to `PAY-01`, `PRI-02` and `PRI-03` after verification. Privacy implementation verification ran `node --test --test-isolation=none backend/privacy-data.test.js` locally against PGlite's PostgreSQL engine. The suite also executes the actual purge function and export route without starting the application or workers. No production account was deleted or payment created. Keep the remaining operational, legal and independent-assessment requirements open; a code fix closes only its supported engineering gap.
